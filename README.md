# Slap or Bomb

Website for the Roblox game [Slap or Bomb](https://www.roblox.com/games/107846844939325/slap-or-bomb).

Plain HTML/CSS/JS, no build step. Hosted free on GitHub Pages.

- Links (Roblox, Discord): `ROBLOX_URL` / `DISCORD_URL` at the bottom of `index.html`
- Shop items and Robux prices: the `SHOP` list in `index.html`
- Images: `assets/`
